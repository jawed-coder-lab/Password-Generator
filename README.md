Password Generator

A simple Python password generator that creates random passwords with letters, numbers, and symbols.

Features

- Choose the password length
- Include or exclude letters
- Include or exclude numbers
- Include or exclude symbols
- Makes sure selected character types are included
- Uses "secrets" for secure random generation
- Handles invalid input

How to Run

python randompassword.py

Then enter the password length and choose which types of characters you want to include.

Example

--- Advanced Password Generator ---

Enter password length: 12
Include letters? (yes/no): yes
Include numbers? (yes/no): yes
Include symbols? (yes/no): yes

Generated password:
f8@K2#mP9$xQ

Requirements

- Python 3.x
- No external libraries required
